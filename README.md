# BLACK RAZOR

Русскоязычный концепт премиального барбершопа для портфолио. Next.js 16,
React 19, Tailwind CSS 4, Framer Motion. Сервер и база данных для записи не нужны.

## Запуск на компьютере

Установите Node.js 22 или 24. В папке проекта выполните:

```sh
npm ci
npm run dev
```

Откройте адрес, который покажет Next.js (обычно http://localhost:3000).
Для готовой сборки: `npm run build`, затем `npm start`.

## Открыть на телефоне

Если запускаете на своём компьютере: подключите телефон и компьютер к одной
сети Wi-Fi. Найдите локальный IP компьютера (например, 192.168.1.10) и в браузере
телефона откройте `http://192.168.1.10:3000`, подставив свой IP. Если не открывается,
разрешите Node.js доступ к частной сети в брандмауэре компьютера. Адрес localhost
на телефоне не откроет сайт с компьютера. Этот способ относится к локальному
компьютеру, а не к облачной машине Codex.

После публикации просто откройте выданную HTTPS-ссылку на телефоне — общая сеть
больше не нужна.

## Публикация через Vercel

1. Загрузите эти файлы в свой репозиторий GitHub.
2. Войдите на https://vercel.com и выберите Add New → Project.
3. Импортируйте репозиторий BarbershopRazor. Framework Preset: Next.js.
4. Нажмите Deploy. Дополнительные переменные окружения не нужны.
5. Откройте адрес проекта, который выдаст Vercel, на компьютере или телефоне.

Публикация не выполняется командой `npm run build`: эта команда только проверяет
и собирает проект. Публичный адрес появляется после успешного развёртывания.

## Демонстрационная запись

- Выбор услуги, мастера, даты (завтра — 60 дней вперёд) и времени по Киеву.
- Цены в гривнах; проверка имени, телефона, даты и обязательного выбора слота.
- Учитываются продолжительность услуги, закрытие в 20:00 и пересечения записей
  того же мастера в этом браузере.
- Данные хранятся в localStorage под ключом `black-razor-bookings-v1`.
- Реальной отправки, SMS и бронирования нет. Лучше использовать вымышленные данные.
- Для удаления записей очистите данные этого сайта в настройках браузера.
- Данные разных браузеров и устройств не синхронизируются. localStorage не является
  системой бронирования и не гарантирует блокировку при одновременных действиях
  в нескольких вкладках.

## Проверки

```sh
npm run build
npx playwright install chromium
npm run test:e2e
```

В облачной машине используется `/usr/bin/chromium`. Для другого компьютера удалите
`executablePath` из `playwright.config.ts`, чтобы Playwright использовал свой Chromium.
Проверки запускаются для компьютера и мобильного экрана 390×844: навигация,
изображения, отсутствие горизонтальной прокрутки, обязательные поля, формат
телефона, запись, сохранение после перезагрузки, занятые слоты, ошибка хранилища
и предпочтение уменьшения анимации.

Фотографии оптимизируются Next Image и загружаются отложенно, кроме первого экрана.
Шрифты системные, внешних запросов к Google Fonts нет. Источник иллюстраций:
[PHOTO-CREDITS.md](PHOTO-CREDITS.md).
